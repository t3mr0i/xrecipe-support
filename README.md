# xRecipe support

Support, bug reports and feature requests for **xRecipe**, an independent coffee recipe app for the web and iPhone.

- [Report a problem](https://github.com/t3mr0i/xrecipe-support/issues/new?template=bug.yml)
- [Suggest an improvement](https://github.com/t3mr0i/xrecipe-support/issues/new?template=feature.yml)
- [Help and support](https://www.xrecipe.de/support)
- [Privacy policy](https://www.xrecipe.de/privacy)

Issues and attachments are public. Never post account email addresses, passwords, tokens, private photos or raw account logs. For account deletion, use **Settings → Delete account** in xRecipe. Describe other account problems without personal details.

For Bluetooth issues, include your xBloom model, firmware version, iPhone/iOS version and the exact action that failed. Direct Studio control is experimental until verified for the relevant firmware. Keep the machine attended and use its physical controls if a start or stop is not confirmed.

This repository contains support forms only. xRecipe is not affiliated with or endorsed by xBloom. Manufacturer firmware updates and manufacturer support remain available through the official xBloom app.
